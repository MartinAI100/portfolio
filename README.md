# Portfolio de Martín José García Navarro

Portfolio académico desarrollado con HTML5 para la asignatura Desarrollo de Web y de Apps.

## Web

Web: https://martinai100.github.io/portfolio/

Repositorio: https://github.com/MartinAI100/portfolio

## Páginas

- `index.html`: presentación, habilidades, formación y proyectos destacados.
- `proyectos.html`: proyectos, tecnologías utilizadas y metodología de trabajo.
- `contacto.html`: formulario de contacto con validación nativa de HTML5.
- `sobre-mi.html`: trayectoria, cronología, multimedia, preguntas frecuentes y niveles de Python, Java y SQL.

Las imágenes, el logo, el favicon y la imagen de Open Graph están en `img/`.
