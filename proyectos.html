Investigación

Estudio de patrones de cibertráfico IoT

Estudié el dataset RT-IoT2022 mediante análisis exploratorio, reducción de dimensionalidad con PCA, agrupamiento con K-Means y Fuzzy C-Means, clasificación supervisada e interpretabilidad con SHAP, LIME y ELI5.

Preparé los datos, comparé modelos e interpreté los resultados. Analicé estadísticas de los flujos, como tiempos, volumen y banderas, sin inspeccionar el contenido de los paquetes.

Los resultados corresponden al entorno controlado del dataset. Las clases con pocos ejemplos requieren cautela.

Con este proyecto aprendí a organizar un estudio desde la preparación de los datos hasta la comparación de modelos, combinar técnicas de agrupamiento y clasificación y analizar sus resultados mediante herramientas de interpretabilidad.

Tecnologías y herramientas que utilicé:

  • Python
  • Jupyter Notebook
  • PCA para reducción de dimensionalidad
  • K-Means y Fuzzy C-Means para clustering
  • Clasificación y predicción con Extra Trees, Random Forest, XGBoost, AdaBoost y Gradient Boosting
  • Árboles de decisión, KNN, regresión logística, análisis discriminante lineal y Gaussian Naive Bayes
  • SHAP, LIME y ELI5 para interpretabilidad

Consultar el repositorio del estudio de cibertráfico IoT en GitHub

Mi artículo (2026): Aprendizaje supervisado, clustering difuso e interpretabilidad con un enfoque KDD-XAI para la caracterización del cibertráfico IoT en un entorno controlado de forma privada.

Investigación astronómica con Astroquery

Analicé datos de estrellas cercanas, exoplanetas y meteoritos. Combiné consultas a catálogos astronómicos, limpieza de datos, cálculos y visualizaciones para estudiar sus distribuciones y características.

Aprendí a consultar fuentes astronómicas con Python, trabajar con unidades y coordenadas, filtrar datos y contrastar las conclusiones con los criterios y límites de la muestra.

Tecnologías y herramientas que utilicé:

  • Python y Jupyter Notebook
  • Astroquery y Astropy
  • NumPy y pandas
  • Matplotlib y Seaborn

Programación

GeoDraw: editor de figuras geométricas

GeoDraw es una aplicación de escritorio para crear y editar figuras geométricas sobre un lienzo. Permite moverlas, cambiar sus colores, eliminarlas, guardar y cargar dibujos y consultar estadísticas de las figuras.

Con este proyecto aprendí a representar figuras mediante clases, aplicar herencia y polimorfismo, separar responsabilidades con el patrón MVC y conectar eventos de una interfaz gráfica con el modelo de la aplicación.

Tecnologías y herramientas que utilicé:

  • Java
  • Swing y AWT
  • Serialización de objetos para guardar y cargar figuras
  • UML para documentar las clases

Chesscraping: análisis de datos de ajedrez

En este proyecto trabajé con la extracción, el almacenamiento y el análisis de datos de ajedrez: estadísticas de jugadores y partidas, clasificación de aperturas ECO, visualizaciones y experimentos de predicción con XGBoost.
